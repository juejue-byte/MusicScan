# MusicScan

An interactive side-by-side **Optical Music Recognition (OMR)** studio powered by [`homr`](https://github.com/liebharc/homr) (Transformer-based OMR), featuring:

- **Side-by-side review**: Original sheet music scan with detected staff/measure confidence overlays synced to an interactive SVG sheet music renderer.
- **Low-confidence & beat-math flagging**: Automatically flags measures with duration mismatches or unusual register jumps so you only review uncertain bars.
- **Measure-by-measure editing**: Click any note to tweak pitch, accidentals, octave, duration, dots, or rests; add/delete notes and measures; or fix a global time signature in one click.
- **Instant playback & export**: Built-in Web Audio API synthesizer with BPM control, plus one-click **MusicXML (`.musicxml`)** (for MuseScore/Dorico/Sibelius) and **MIDI (`.mid`)** export.

## Project Structure

```text
MusicScan/
├── index.html          # Standalone OMR Studio web app (GitHub Pages ready)
├── omr_data.js         # Parsed homr inference outputs for sample scores
├── image.png           # Sample 1: Vintage printed piano score
├── image_2.png         # Sample 2: Printed monophonic horn signals
├── image_3.png         # Sample 3: Handwritten antique piano score
├── musicxml/           # Raw MusicXML files generated by homr
├── scripts/
│   └── parse_omr.py    # Parses homr MusicXML + staff boxes into omr_data.js
└── requirements.txt    # Python dependencies for running homr locally
```

## Quick Start

### View the Web App
Open `index.html` directly in your browser (or enable **GitHub Pages** on the `main` branch).

### Run `homr` on New Sheet Music
```bash
pip install -r requirements.txt
homr --write-staff-positions --no-title your_score.png
```
This outputs `your_score.musicxml` and `your_score.txt` (detected staff positions), which can be parsed into `omr_data.js` using `scripts/parse_omr.py`.
